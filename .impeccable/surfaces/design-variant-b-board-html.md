# Рабочие экраны AI-CRM, вариант B

Scope: воронка, карточка сделки, отчёт. Visitor mode: Operate.
Audience: владелец малого бизнеса услуг (телефон, между делами) и 1-5 менеджеров (ноутбук, весь день).
Task: увидеть, что требует ответа сейчас, провести сделку по стадиям, понять, где деньги.
Concept features shown: «Спроси CRM», «Следующий шаг в один клик», «Шанс сделки».
Constraints: без внешних запросов (шрифты свои), светлая и тёмная тема по системе, стандартные веб-контролы, у перетаскивания есть альтернатива кнопкой, статус не передаётся одним цветом.

## Direction contract

THESIS: CRM читается как журнал администратора, который вёл ресепшен годами: что важно, отмечено маркером. Отказ от доски из одинаковых карточек с серой тенью и цветными полосками статусов.

OWN-WORLD: белый лист, чернила шариковой ручки #2B4CC8 для всего, что вписал человек, графитовый текст интерфейса, красная линия полей #E2483D только для просрочки, три маркера-текстовыделителя: жёлтый «ответить сегодня», розовый «просрочено», мятный «сделка». Golos Text во всех размерах, тонкие линейки 1px, скругления 4px.

STORY: владелец открывает воронку и за секунду видит маркерные строки: кому ответить и где деньги горят; менеджер ведёт запись строка за строкой; ИИ подписывает шанс и следующий шаг на полях карандашом, а не кричит.

FIRST VIEWPORT: слева узкая боковая навигация, сверху строка «Спросить журнал» на всю ширину рабочей области, под ней дата-заголовок дня и три суммы; ниже пять колонок стадий плотными записями по две строки, маркер под именем срочных; «Новая заявка» справа от заголовка дня.

FORM: «Журнал записи администратора», кандидат 1 из моего списка (IMPECCABLE’S PICK, выбран пользователем), seed key c5ef487c. Signature move: маркер прорисовывает срочные записи слева направо один раз при открытии.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
