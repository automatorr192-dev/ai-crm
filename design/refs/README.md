# Референсы AI-CRM

Собраны 11.10.2026 с SaaSUI.design (https://www.saasui.design, раздел Dashboard): реальные экраны выпущенных продуктов. Берём механику, а не внешний вид: визуальный мир остаётся «Банкнотой».

| Файл | Продукт | Приём | Почему подходит нам |
|---|---|---|---|
| `saasui-close-crm-2.png` | Close CRM, карточка лида | Одна лента событий справа, над ней кнопки «Note / Email / SMS / Call»: любое действие с клиентом пишется в одно место. Слева компактные блоки с числом в заголовке (Tasks 0, Opportunities 1, Contacts 1) и «+» у каждого | У нас комментарии, переписка, файлы и история — четыре отдельные панели. Менеджеру приходится собирать картину сделки по кускам |
| `saasui-attio-2.png` | Attio, канбан воронки | Внизу каждой колонки «Add calculation»: сумма, среднее, количество, процент заполненных; у стадии цветная точка; «Add to list» в каждой колонке | Быстро добавить заявку прямо в нужную стадию; итог колонки по выбору (сумма или средний чек) |
| `saasui-trello-1.png` | Trello, доска | «+ Add a card» внизу каждой колонки, плотные карточки без лишних полей | Ручная заявка (звонок, встреча) заводится прямо на доске, без перехода на отдельную страницу |
| `saasui-trello-4.png` | Trello, фильтр доски | Панель фильтра: «Просрочено», «Срок в ближайший день», «Мои карточки», метки | У нас фильтр только по сотруднику; «просрочено» и «срок сегодня» — то, что владелец ищет каждое утро |
| `saasui-close-crm-1.png` | Close CRM, обзор активности | Плитки показателей с выбором периода и «Compare to» (сравнить с прошлым периодом) | В отчёте показатели без динамики: «22 заявки» ничего не говорят, пока не видно, больше это или меньше, чем в прошлом месяце |
| `saasui-hubspot-1.jpg` | HubSpot, дашборд продаж | «Deals closed vs Goal» — линия плана против факта, «Deal Forecast» с квотой | Владелец малого бизнеса мыслит планом на месяц: сколько уже закрыли от цели |
